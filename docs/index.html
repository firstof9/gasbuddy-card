Installation

      

        

          
HACS (Recommended)

          
    
            
  1. Click the Home Assistant badge above, or open HACS in Home Assistant.
    2. 
            
  2. Open the menu (three dots) → Custom repositories.
    3. 
            
  3. Add https://github.com/firstof9/gasbuddy-card with category Dashboard.
    4. 
            
  4. Download GasBuddy Card and add custom:gasbuddy-card via the Visual Editor.
    5. 
          

        

        

          
Manual

          
    
            
  1. Download gasbuddy-card.js from the latest release.
    2. 
            
  2. Copy it to <config>/www/gasbuddy-card.js.
    3. 
            
  3. Register /local/gasbuddy-card.js as a JavaScript module under Settings → Dashboards → Resources.
    4.
